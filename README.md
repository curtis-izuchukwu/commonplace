# PararePilot

PararePilot is an offline-first JavaFX desktop application for planning study, tracking worksheet attempts, identifying weak topics, and guiding targeted revision from local progress data.

## Milestone 1

This milestone establishes the JavaFX/Maven foundation:

- Java 21
- JavaFX 21
- Maven build
- SQLite JDBC dependency
- JUnit 5 test support
- Initial styled desktop window

## Requirements

- JDK 21
- Maven 3.9 or newer

## Build

```bash
mvn test
```

## Run

```bash
mvn javafx:run
```

## Project Structure

Application source lives under `src/main/java/com/pararepilot`.

JavaFX resources live under `src/main/resources/com/pararepilot`.
